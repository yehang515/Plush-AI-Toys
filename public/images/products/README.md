# Product media

Place product images in this folder.

Recommended formats: `.webp` for production images, `.png` for transparent cutouts, and `.jpg` for photography. Use descriptive, lowercase filenames such as `ai-companion-bear.webp`.

Files in `public/` are served unchanged. Reference an image on the current GitHub Pages site as:

```text
/Plush-AI-Toys/images/products/your-image.webp
```

When the custom `.com` domain is connected and `BASE_PATH` is set to `/`, use:

```text
/images/products/your-image.webp
```
